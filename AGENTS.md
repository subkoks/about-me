# AGENTS.md

Repo-specific guidance for Codex CLI and other agents working in this repository.

## Scope

- This repo is documentation only: the long-form about page for `subkoks/about-me`.
- Keep Markdown links and badge URLs valid and current.
- Prefer small, single-purpose edits over broad rewrites.
- Cross-link to related repos instead of duplicating profile content.

## Operating rules

- Read `README.md` and `CLAUDE.md` before editing.
- Work on a feature branch and keep one logical change per commit.
- Keep the repo docs-first and avoid adding application code.
- Use repo-local `.codex/config.toml` for Codex defaults in this workspace.
